# AI Engineer & Full Stack Portfolio 🚀

A premium, modern research-oriented portfolio website built for AI Engineers and Full Stack Developers.

## ✨ Features

- **AI/Research Aesthetic**: Futuristic dark theme with interactive floating background blobs.
- **Modern UI/UX**: Glassmorphism effects, gradient glow borders, and premium typography.
- **Smooth Animations**: Intersection Observer based scroll reveals, high-frequency typing effect, and parallax interactions.
- **Specialized Sections**: Education timeline (M.Tech @ NIT Silchar), Research Interests, AI/ML Skills, and Achievements.
- **Fully Responsive**: Optimized for all devices with a modern mobile navigation system.
- **Fast & Lightweight**: Built with Vanilla HTML, CSS, and JS for maximum performance.

## 🛠️ Customization Guide

### 1. Change Your Details
Update `index.html` with your specific information:
- **Roles**: Modify the `words` array in `script.js` for the typing effect.
- **Education/Journey**: Update the `.timeline` section in `index.html`.
- **Contact Info**: Update the `.contact-info` and footer sections.

### 2. Update Projects
To add or change projects, find the `.projects-grid` in `index.html`. Replace the `src` of the images and the description text.

### 3. Theme Colors
Modify the `:root` variables in `style.css`:
```css
:root {
    --primary: #6366f1; /* Indigo-500 */
    --secondary: #06b6d4; /* Cyan-500 */
    --accent: #d946ef; /* Fuchsia-500 */
}
```

## 🚀 Deployment

- **GitHub Pages**: Push to a repo and enable Pages in Settings.
- **Netlify**: Drop the folder onto the Netlify app.
- **Vercel**: Run `vercel` in the terminal.
